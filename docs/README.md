# Docsify サンプル

Docsifyで公開するドキュメントサイトのサンプルです。Markdownファイルを追加すると、ページとしてそのまま表示できます。

## このサイトについて

- 左のサイドバーからページを移動できます
- 見出しからページ内リンクが自動生成されます
- Markdownの編集結果はブラウザーを再読み込みすると反映されます

## ページ

- [はじめる](guide.md)
- [Markdownの例](markdown.md)

## ローカルで表示する

このディレクトリで簡易HTTPサーバーを起動し、表示されたURLをブラウザーで開いてください。

```bash
python3 -m http.server 8000
```
